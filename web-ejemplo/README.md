# Mi página web

Una práctica básica de HTML y CSS para aprender los fundamentos del desarrollo web.

## Descripción

Este proyecto contiene una página web simple que muestra cómo se estructuran y se estilizan los elementos HTML usando CSS. Es ideal para quienes se están iniciando en el desarrollo web.

## Archivos del proyecto

- **index.html** - Archivo principal que contiene la estructura de la página
- **styles.css** - Archivo de estilos que define la apariencia visual
- **README.md** - Este archivo con información sobre el proyecto

## Estructura de la página

La página está dividida en tres secciones principales:

### Header (Encabezado)
Contiene el título principal y un subtítulo de la página.

### Main (Contenido principal)
Muestra dos tarjetas informativas sobre HTML y CSS con una breve descripción de cada uno.

### Footer (Pie de página)
Contiene información sobre la práctica del curso.

## Conceptos incluidos

### HTML
- Etiquetas semánticas: `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`
- Estructura básica de un documento HTML
- Atributos de clase para identificar elementos

### CSS
- Reset de estilos por defecto
- Propiedades de color y fondo
- Tipografía y espaciado
- Flexbox para alineación
- Bordes y bordes redondeados

## Cómo usar

1. Abre el archivo `index.html` en tu navegador web
2. Observa cómo se aplican los estilos CSS a los elementos HTML
3. Modifica los estilos en `styles.css` para practicar cambios visuales

## Próximos pasos

Para mejorar tu práctica, puedes intentar:
- Cambiar los colores del encabezado y footer
- Agregar más tarjetas al contenido
- Experimentar con tamaños de fuente y espaciado
- Añadir efectos hover en las tarjetas
- Hacer la página responsive para dispositivos móviles
